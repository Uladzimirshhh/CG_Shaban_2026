### 3. Теоретические сведения

#### 3.1. Модель RGB
Аддитивная модель (мониторы, проекторы). Принцип — сложение излучаемых световых потоков трех длин волн. Координаты R, G, B ∈ [0, 255]. Точка (0, 0, 0) — черный цвет, (255, 255, 255) — белый цвет.

#### 3.2. Модель CMYK
Субтрактивная модель (полиграфия, печать). Принцип — поглощение длин волн отражающей поверхностью. Координаты C, M, Y, K ∈ [0, 100]%. Компонента K (Key) добавлена из-за примесей в реальных цветных красках (невозможно получить глубокий черный цвет смешением C+M+Y), удешевления печати и исключения размытия мелкого текста при неприводке пластин.

#### 3.3. Модель HLS
Перцепционная модель, основанная на восприятии человеческого зрения. Геометрически представляет собой двойной конус (биконус):
* H (Hue) — цветовой тон, [0°, 360°).
* L (Lightness) — светлота, [0, 100]%. Чистые спектральные цвета лежат строго на экваторе при L = 50%. При L = 0% цвет черный, при L = 100% — белый.
* S (Saturation) — насыщенность, [0, 100]%. При S = 0% цвет становится нейтрально-серым, а тон H теряет смысл.

### 4. Алгоритмы пересчета

1. RGB -> CMYK:

   r = R/255, g = G/255, b = B/255
   
   K = min(1-r, 1-g, 1-b)
   
   C = (1-r-K)/(1-K), M = (1-g-K)/(1-K), Y = (1-b-K)/(1-K) (при K < 1)

2. CMYK -> RGB:

   R = 255 * (1-C/100) * (1-K/100)
   
   G = 255 * (1-M/100) * (1-K/100)
   
   B = 255 * (1-Y/100) * (1-K/100)

3. RGB -> HLS:

   Вычисляются max, min, delta.
   L = (max + min) / 2
   S = delta / (max + min) при L <= 0.5, иначе delta / (2 - max - min)
   H рассчитывается по формуле сектора доминирующего цветового канала * 60°.

4. HLS -> RGB:

Преобразование HLS в RGB основано на вычислении граничных параметров светлоты и насыщенности с последующим раздельным определением каналов R,G,B через кусочно-линейную интерполяцию цветового тона с фазовым сдвигом в 120∘.

### 5. Описание реализации
Приложение разработано в виде автономного веб-интерфейса с использованием стандартов HTML5, CSS3 и чистого JavaScript (ES6+) без применения сторонних фреймворков и библиотек.

Интерфейс разделен на логические уровни:
1. **Информационная панель:** заголовок, указание нечетного варианта и автора работы.
2. **Панель оперативного контроля:** 
   * крупное окно предпросмотра текущего цвета с динамической тенью в тон выбранного оттенка;
   * интерактивный блок вызова графической палитры (нативный системный color picker);
   * текстовое поле для прямого ввода и отображения цвета в формате HEX.
3. **Рабочая сетка моделей (CMYK, RGB, HLS):** отдельные независимые карточки для каждой модели. Каждый канал снабжен буквенной меткой, интерактивным ползунком с динамической цветной заливкой шкалы и числовым полем точного ввода.

**Ключевые технические особенности реализации:**
* **Архитектура синхронизации без рекурсии:** Взаимный пересчет реализован через централизованный диспетчер `syncAll(r, g, b, caller)`. Для предотвращения эффекта зацикливания событий (*feedback loop*) используется булевый флаг `isUpdating`. При изменении координаты в любой модели вычисляется эталонный цвет, который затем транслируется во все остальные каналы без повторного вызова событий обновления.
* **Строгая валидация и фильтрация ввода:** 
  * На уровне событий клавиатуры (`keydown`) и потока ввода (`input`) внедрена фильтрация нецифровых символов с помощью регулярных выражений. Ввод букв, знаков пунктуации, отрицательных чисел и спецсимволов физически заблокирован.
  * Реализовано автоматическое ограничение диапазона (*clamping*): при попытке ввести число выше максимума (например, $>255$ для RGB или $>100$ для CMYK/L/S) значение моментально корректируется до верхней границы.
  * При опустошении поля активируется визуальная индикация ошибки (красная рамка), а при потере фокуса (`blur`) значение корректно восстанавливается до текущего валидного состояния.
* **Эргономика интерфейса:** оформление выполнено в современной светлой бело-серой палитре с повышенной контрастностью элементов управления и индикаторов шкал.

### 7. Выводы
В ходе выполнения лабораторной работы были подробно изучены теоретические основы колориметрии и принципы функционирования трех базовых классов цветовых моделей:
1. **Аддитивной (RGB)**, моделирующей излучаемый свет мониторов путем сложения базовых спектральных полос;
2. **Субтрактивной (CMYK)**, описывающей процесс поглощения света полиграфическими красками на бумаге, где введение ключевого черного канала ($K$) обосновано физическими примесями пигментов, технологической точностью печати тонких линий и экономической целесообразностью;
3. **Перцепционной (HLS)**, воспроизводящей интуитивное восприятие цвета человеком в форме двойного конуса, где чистые спектральные цвета сосредоточены на экваторе при светлоте $L = 50\%$, а крайние значения $L = 0\%$ и $L = 100\%$ вырождаются соответственно в абсолютно черный и белый цвета.

Разработано полнофункциональное интерактивное веб-приложение, обеспечивающее точное задание цвета тремя независимыми способами (поля ввода, ползунки, палитра) и мгновенный двусторонний пересчет координат в реальном времени. Внедренные алгоритмы фильтрации исключают ввод некорректных данных, а математическая реализация полностью обеспечивает сохранение цветовых координат в рамках допустимых погрешностей дискретизации.
