### 3. Теоретические сведения

#### 3.1. Локальная пороговая обработка: Метод Ниблэка (Niblack)
Локальный адаптивный метод бинаризации, где порог отсечения вычисляется индивидуально для каждого пикселя (x, y) по статистическим характеристикам окрестности размером W × W:
T(x, y) = m(x, y) + k * s(x, y)
где:
* m(x, y) — локальное среднее значение яркости;
* s(x, y) — локальное стандартное отклонение (СКО);
* k — коэффициент чувствительности (стандартно k ≈ -0.2).

В областях с низкой яркостью локальное среднее m уменьшается, что приводит к адаптивному снижению порога T. На однородных светлых участках листа при околонулевой дисперсии (s -> 0) порог приближается к локальному среднему значению (T ≈ m).

#### 3.2. Глобальный метод Оцу (Otsu)
Вычисляет единый порог T* для всего кадра, максимизирующий межклассовую дисперсию между объектом и фоном:
sigma_B^2(T) = omega_0(T) * omega_1(T) * [mu_0(T) - mu_1(T)]^2 -> max
Алгоритм опирается исключительно на глобальную гистограмму распределения уровней яркости и не учитывает пространственное расположение пикселей на плоскости изображения.

#### 3.3. Высокочастотные фильтры (увеличение резкости)
Высокочастотные фильтры подавляют низкие пространственные частоты (плавные градиенты, однородные области) и усиливают высокочастотные составляющие (контуры, перепады яркости). Реализуются операцией двумерной свертки с ядром 3×3:
g(x, y) = sum_{dy} sum_{dx} f(x + dx, y + dy) * K(dy, dx)

1. Ядро повышения резкости (Sharpening 3×3):
   K_sharp = [[0, -alpha, 0], [-alpha, 1 + 4*alpha, -alpha], [0, -alpha, 0]]
   Сумма весовых коэффициентов ядра строго равна 1 при любом alpha, что сохраняет среднюю интегральную яркость изображения. При alpha = 0.0 матрица вырождается в единичную (Identity), не изменяя исходный сигнал.
2. Оператор Лапласа:
   K_lap = [[0, -alpha, 0], [-alpha, 4*alpha, -alpha], [0, -alpha, 0]]
   Сумма элементов ядра равна 0. Все однородные участки обнуляются, а ненулевой отклик формируется строго на границах перепада яркостей.
3. Нерезкое маскирование (Unsharp Masking):
   g(x, y) = f(x, y) + alpha * (f(x, y) - f_blur(x, y))
   где f_blur — результат низкочастотной гауссовой фильтрации. Разность (f - f_blur) представляет собой карту высокочастотных деталей, которая с весом alpha суммируется с исходным изображением.

### 4. Алгоритмы обработки

1. Локальная бинаризация Ниблэка:
   m = mean(I, W), s = std(I, W)
   T = m + k * s
   I_out(x, y) = 255, если I(x, y) >= T, иначе 0

2. Глобальная бинаризация Оцу:
   Вычисляется гистограмма яркостей кадра. Находится порог T*, максимизирующий межклассовую дисперсию:
   T* = argmax_t (omega_0(t) * omega_1(t) * [mu_0(t) - mu_1(t)]^2)
   I_out(x, y) = 255, если I(x, y) >= T*, иначе 0

3. Матричная резкость 3×3:
   I_out(x, y) = clamp(sum_{dy, dx} I(x+dx, y+dy) * K_sharp(dy, dx), 0, 255)

4. Оператор Лапласа:
   I_out(x, y) = clamp(sum_{dy, dx} I(x+dx, y+dy) * K_lap(dy, dx) + 128 * min(1.0, alpha), 0, 255)

5. Нерезкое маскирование:
   I_blur = I * K_gauss
   I_out = clamp(I + alpha * (I - I_blur), 0, 255)

### 5. Описание реализации
Приложение разработано в виде десктопного графического интерфейса на языке Python 3 с использованием библиотек Tkinter, NumPy и Pillow.

Интерфейс разделен на логические уровни:
1. Информационная панель: заголовок, указание дисциплины, варианта 13, наименование исследуемых алгоритмов и авторство работы (Шабан Владимир).
2. Панель оперативного управления базой изображений:
   * выпадающий список файлов, автоматически формируемый при сканировании каталога images/;
   * кнопка принудительного обновления списка файлов без перезапуска программы;
   * диалоговое окно добавления произвольных файлов пользователя с сохранением копии в каталог images/.
3. Рабочая сетка параметров (Метод 1 и Метод 2):
   * Блок пороговой обработки: радиокнопки («Ниблэк (лок.)», «Оцу (глоб.)», «Откл.»), слайдер размера окна W ∈ [5, 45], слайдер коэффициента k ∈ [-1.0, 1.0].
   * Блок высокочастотной фильтрации: радиокнопки («Резкость 3×3», «Лаплас», «Unsharp Mask», «Откл.»), слайдер силы резкости alpha ∈ [0.0, 3.0].
4. Область визуального контроля: симметричные карточки «Оригинальное изображение» и «Результат обработки» в реальном времени.

Ключевые технические особенности:
* Оптимизация локальной статистики O(1): вычисление скользящего среднего m и СКО s через двумерное интегральное накопление (np.cumsum) исключает вложенные циклы Python, сокращая время расчета кадра до 2–5 мс.
* Строгая блокировка и индикация параметров: при выборе режима «Откл.» (а также в режиме Оцу) связанные слайдеры аппаратно блокируются (disabled), а их метки приобретают светло-серый оттенок (#cbd5e1).
* Фиксация геометрии и пропорциональная подгонка: область просмотра зафиксирована контейнерами постоянного размера (480×340 px) с пропорциональным масштабированием кадра (LANCZOS) без деформации и скачков окон.
* Эргономика: светлая бело-серая тема оформления с повышенной контрастностью элементов.

### 6. Выводы
1. Метод Ниблэка формирует порог бинаризации индивидуально для каждого пикселя на основе локального среднего m и стандартного отклонения s в скользящем окне W × W. При околонулевом значении СКО (s -> 0) на однородных участках порог стремится к среднему значению (T ≈ m).
2. Глобальный метод Оцу определяет единое пороговое значение для всего изображения путем максимизации межклассовой дисперсии между фоном и объектом, используя исключительно данные интегральной гистограммы распределения яркостей.
3. Ядро пространственного повышения резкости обладает суммой весовых коэффициентов, равной единице, благодаря чему сохраняется интегральная средняя яркость изображения при увеличении локального краевого контраста. При значении коэффициента alpha = 0.0 оператор свертки вырождается в единичную матрицу (тождественное преобразование).
4. Дискретный оператор Лапласа аппроксимирует вторую пространственную производную (nabla^2 f) и обладает нулевой суммой весовых коэффициентов ядра, за счет чего полностью подавляет постоянную составляющую на однородных участках и формирует ненулевой отклик исключительно на перепадах яркости.
5. Любые пространственные высокочастотные дифференциальные фильтры усиливают все высокочастотные составляющие сигнала, включая высокочастотный шум сенсора изображения.

Разработанный на языке Python программный комплекс с графическим интерфейсом реализует алгоритмы пороговой бинаризации и высокочастотной фильтрации в полном соответствии с требованиями учебной программы.
