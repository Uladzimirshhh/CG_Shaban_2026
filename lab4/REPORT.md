## 2. Описание реализованного приложения

Приложение моделирует отсечение набора отрезков и выпуклых многоугольников прямоугольным окном `[Xmin, Ymin, Xmax, Ymax]` в декартовой системе координат.

**Функциональность программы:**
- переключение между двумя режимами работы (Сазерленд–Коэн для отрезков и Сазерленд–Ходжмен для выпуклого многоугольника);
- ввод и редактирование входных данных в формате из задания (`n`, затем `n` строк координат и строка границ отсекающего окна), а также добавление отрезков и вершин кликами мыши по координатной сетке;
- вывод декартовой системы координат с осями `X` и `Y`, адаптивной сеткой и числовыми подписями;
- автоматическое масштабирование (`Автомасштаб`), плавный зум колёсиком мыши и панорамирование правой кнопкой;
- цветовое разделение объектов на экране:
  - **синий** — отсекающее прямоугольное окно;
  - **красный пунктир** — исходные отрезки / исходный многоугольник;
  - **зелёная толстая линия** — видимые части объектов после отсечения.

## 3. Описание алгоритмов и расчёты на примерах

### 3.1. Часть 1. Алгоритм Сазерленда–Коэна

#### Принцип работы
Четыре прямые, содержащие стороны прямоугольного окна, разбивают плоскость на 9 областей. Каждой конечной точке отрезка $(x, y)$ ставится в соответствие 4-битный код:
- бит 3 (`1000` = 8, `TOP`): $y > Y_{\max}$;
- бит 2 (`0100` = 4, `BOTTOM`): $y < Y_{\min}$;
- бит 1 (`0010` = 2, `RIGHT`): $x > X_{\max}$;
- бит 0 (`0001` = 1, `LEFT`): $x < X_{\min}$.

Алгоритм выполняет:
1. Если `code1 == 0` и `code2 == 0`, отрезок **тривиально видим** и принимается целиком.
2. Если `(code1 & code2) != 0`, оба конца лежат за одной и той же стороной окна — отрезок **тривиально невидим** и сразу отбрасывается.
3. Иначе выбирается внешняя точка (`code != 0`) и находится её пересечение с соответствующей границей окна по уравнению прямой:
   - при пересечении горизонтальной границы ($y = Y_{\min}$ или $y = Y_{\max}$):
     $$x = x_1 + (x_2 - x_1) \cdot \frac{y - y_1}{y_2 - y_1}$$
   - при пересечении вертикальной границы ($x = X_{\min}$ или $x = X_{\max}$):
     $$y = y_1 + (y_2 - y_1) \cdot \frac{x - x_1}{x_2 - x_1}$$

   Внешняя точка заменяется точкой пересечения, её код пересчитывается, и проверка повторяется до полного принятия или отбрасывания.

#### Пример расчёта (демонстрационная сцена из программы)
Окно отсечения: $X_{\min} = -5,\ Y_{\min} = -3,\ X_{\max} = 10,\ Y_{\max} = 7$.

| № | Исходный отрезок | Коды концов | Ход отсечения | Результат |
|---:|---|:---:|---|---|
| 1 | $(-8, -4) \to (12, 8)$ | `0101`, `1010` | 1) $P_1$ по $y=-3 \Rightarrow (-6.333, -3)$ (`0001`)<br>2) $P_1$ по $x=-5 \Rightarrow (-5, -2.2)$ (`0000`)<br>3) $P_2$ по $y=7 \Rightarrow (10.333, 7)$ (`0010`)<br>4) $P_2$ по $x=10 \Rightarrow (10, 6.8)$ (`0000`) | **Принят:** $(-5, -2.2) \to (10, 6.8)$ |
| 2 | $(-2, 2) \to (6, 5)$ | `0000`, `0000` | Оба конца внутри окна | **Принят целиком:** $(-2, 2) \to (6, 5)$ |
| 3 | $(-12, 6) \to (-6, 10)$ | `0001`, `1001` | `0001 & 1001 = 0001 != 0` (оба левее $X_{\min}$) | **Отвергнут тривиально** |
| 4 | $(3, -7) \to (3, 11)$ | `0100`, `1000` | 1) $P_1$ по $y=-3 \Rightarrow (3, -3)$<br>2) $P_2$ по $y=7 \Rightarrow (3, 7)$ | **Принят:** $(3, -3) \to (3, 7)$ |
| 5 | $(-10, 4) \to (14, 4)$ | `0001`, `0010` | 1) $P_1$ по $x=-5 \Rightarrow (-5, 4)$<br>2) $P_2$ по $x=10 \Rightarrow (10, 4)$ | **Принят:** $(-5, 4) \to (10, 4)$ |

### 3.2. Часть 2. Алгоритм Сазерленда–Ходжмена

#### Принцип работы
Алгоритм последовательно пропускает список вершин многоугольника через 4 полуплоскости, задаваемые сторонами окна:
1. Левая граница ( $x \ge X_{\min}$);
2. Правая граница ( $x \le X_{\max}$);
3. Нижняя граница ( $y \ge Y_{\min}$);
4. Верхняя граница ( $y \le Y_{\max}$).

На каждом этапе при обходе всех рёбер $S \to E$ формируется новый список вершин по 4 правилам:
- $S$ внутри, $E$ внутри $\implies$ добавляется $E$;
- $S$ внутри, $E$ снаружи $\implies$ добавляется точка пересечения $I$;
- $S$ снаружи, $E$ снаружи $\implies$ ничего не добавляется;
- $S$ снаружи, $E$ внутри $\implies$ добавляются точка пересечения $I$ и затем $E$.

Поочерёдная фильтрация автоматически формирует новые рёбра вдоль границ отсекающего окна, сохраняя замкнутость многоугольника.

#### Пример расчёта (демонстрационная сцена из программы)
Окно отсечения: $X_{\min} = -4,\ Y_{\min} = -3,\ X_{\max} = 10,\ Y_{\max} = 7$.  
Исходный выпуклый шестиугольник: $(-7, 1),\ (-3, 9),\ (6, 10),\ (13, 4),\ (9, -5),\ (-2, -6)$.

1. **Левая граница ( $x \ge -4$):**
   - ребро $(-2, -6) \to (-7, 1)$ выходит наружу $\Rightarrow (-4, -3.2)$;
   - ребро $(-7, 1) \to (-3, 9)$ входит внутрь $\Rightarrow (-4, 7),\ (-3, 9)$;
   - остальные вершины лежат правее $-4$.  
   Список вершин: $(-4, -3.2),\ (-4, 7),\ (-3, 9),\ (6, 10),\ (13, 4),\ (9, -5),\ (-2, -6)$.

2. **Правая граница ( $x \le 10$):**
   - ребро $(6, 10) \to (13, 4)$ выходит наружу $\Rightarrow (10, 6.571)$;
   - ребро $(13, 4) \to (9, -5)$ входит внутрь $\Rightarrow (10, -2.75),\ (9, -5)$.  
   Список вершин: $(-4, -3.2),\ (-4, 7),\ (-3, 9),\ (6, 10),\ (10, 6.571),\ (10, -2.75),\ (9, -5),\ (-2, -6)$.

3. **Нижняя граница ( $y \ge -3$):**
   - ребро $(-4, -3.2) \to (-4, 7)$ входит внутрь $\Rightarrow (-4, -3),\ (-4, 7)$;
   - ребро $(10, -2.75) \to (9, -5)$ выходит наружу $\Rightarrow (9.889, -3)$;
   - ребро $(9, -5) \to (-2, -6)$ и $(-2, -6) \to (-4, -3.2)$ целиком снаружи.  
   Список вершин: $(-4, -3),\ (-4, 7),\ (-3, 9),\ (6, 10),\ (10, 6.571),\ (10, -2.75),\ (9.889, -3)$.

4. **Верхняя граница ( $y \le 7$):**
   - ребро $(-4, 7) \to (-3, 9)$ касается границы в $(-4, 7)$ (дубликат удаляется);
   - ребро $(-3, 9) \to (6, 10)$ целиком снаружи;
   - ребро $(6, 10) \to (10, 6.571)$ входит внутрь $\Rightarrow (9.5, 7),\ (10, 6.571)$.

**Итоговый видимый многоугольник (6 вершин):**  
$$(-4, -3),\ (-4, 7),\ (9.5, 7),\ (10, 6.571),\ (10, -2.75),\ (9.889, -3)$$
